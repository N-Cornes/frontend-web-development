# Front-End Web Development

A multi-page professional website built with semantic HTML, shared CSS styling, and JavaScript. The project presents a resume, cover letter, and career-goals section through a consistent navigation structure and responsive layout.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Semantic HTML

## Site Structure

The website is organized into three primary pages:

- **Resume**
- **Cover Letter**
- **Career Goals**

A shared navigation bar links the pages together so users can move through the site without losing the overall visual structure.

## Resume Page

The resume page includes structured sections for:

- Contact information
- Career objective
- Education
- Technical skills
- Work experience
- Training and certifications

The layout combines a sidebar-style information area with a primary content section for professional experience and other career information.

## Front-End Features

- Multi-page navigation
- Shared stylesheet across pages
- Semantic page sections and headings
- Responsive viewport configuration
- Tables for structured certification data
- Ordered and unordered lists
- Email links
- Internal page navigation
- JavaScript-enhanced dynamic content
- Accessibility-aware markup, including `aria-live` for dynamically updated information

## JavaScript

JavaScript is used to add dynamic behavior to the otherwise static site. The resume page includes a date element that can be updated through the shared script file.

## Page Flow

```text
Resume
   ↕
Cover Letter
   ↕
Career Goals
```

Each page uses the same overall navigation concept so the site feels like one connected professional portfolio rather than separate HTML documents.

## Technical Highlights

This project demonstrates practical front-end fundamentals without relying on a framework. It focuses on clean page structure, reusable styling, navigation, semantic HTML, accessibility considerations, and lightweight JavaScript enhancement.
